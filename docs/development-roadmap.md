# Development Roadmap

1. Backend foundation: configuration, persistence, authentication and tests.
2. Project/team management: memberships, roles and permissions.
3. Task workflow: state transitions, assignment and activity.
4. Git integration: local extension events, commits, branches and diffs.
5. Real-time synchronization: authenticated project WebSockets.
6. React dashboard: project, team, tasks, activity and code changes.
7. VS Code extension: login, project selection, Git status, file tracking and notifications.
8. AI services: Gemini role assistant, debugging and test generation.
9. Intelligence: conflict warnings, contribution summaries and project memory.
10. Integration hardening: end-to-end tests, migrations, deployment and docs.

A milestone is complete only after the user runs verification and reports results.
